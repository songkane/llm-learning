# llm-learning

大模型（LLM）与 MaaS 平台学习资料合集。

按主题分类整理，记录学习过程中的架构分析、源码剖析、原理笔记与实践经验，偏向「建立直觉 + 对照源码」的深入理解，而非 API 罗列。

## 分类导航

|------|------|------|
| 推理引擎 | [`inference-engine/`](inference-engine/) | 大模型推理引擎的架构与源码剖析（vLLM 等） |

> 更多分类（训练、MaaS 平台、Agent、RAG 等）将持续补充。

## 已有内容

### 推理引擎
