# 推理引擎（Inference Engine）

大模型推理引擎的架构与源码学习资料。聚焦「请求如何高效地从字符串走到 GPU 再吐字返回」这一核心问题，剖析调度、显存管理、批处理、分布式部署等关键机制。

推荐按编号顺序阅读，全套沿用统一示例（请求 A、B），层层递进：
